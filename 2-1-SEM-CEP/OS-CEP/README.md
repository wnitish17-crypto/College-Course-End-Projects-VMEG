# Operating Systems Course-End Project

## Project Title
Process Scheduler Implementation

## Subject
Operating Systems Laboratory (A9510)

## Description
This project implements two CPU scheduling algorithms: Preemptive Priority Scheduling and Round Robin Scheduling using the C programming language.

The program accepts process details such as arrival time, burst time, and priority. It calculates completion time, waiting time, response time, average waiting time, and average response time.

## Technologies Used
- C Programming
- Operating Systems Concepts
- CPU Scheduling Algorithms

## Algorithms Implemented
1. Preemptive Priority Scheduling
2. Round Robin Scheduling
